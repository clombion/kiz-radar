Where the data comes from

Festival listings from kizomba-world.com, used under CC BY-SA 4.0; the festival data here is shared under the same licence.

Flight prices are Friday-to-Monday returns from Bergen found on Google Flights with fli, rechecked every few hours. They change often, so check before booking.

Pass prices are read from each festival’s description by Claude, checked against the text, and converted with the European Central Bank’s daily rates.
